When learning a language for the first time I always like to start with a calculator to get a hang of the basics and syntax.

This is a simple CLI Calculator.

**Windows**

If you're on Windows, you can just clone the repository with git and build.

    - Building:

        Inside terminal run: 'build calculator'

    - Dependencies:

        MSVC compiler
        CMake
        Git

**macOS**

If you're on macOS, you can just clone the repository with git and build.

    - Building:

        Inside terminal run: 'build calculator'

    - Dependencies:

        Clang compiler
        CMake
        Git



**Linux**

If you're on Linux, you can just clone the repository with git and build.

    - Building:

        Inside terminal run: 'build calculator'

    - Dependencies:

        GCC compiler
        Make
        CMake
        Git

***NOTES:***
*I'm using the Linux kernel coding style*
